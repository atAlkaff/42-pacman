# Project Management

This folder holds the evidence of how the Pac-Man project was planned,
tracked, and delivered, as required by the subject (chapter VIII).

| File | What it contains |
| --- | --- |
| [01_timeline.md](01_timeline.md) | Planned schedule (Gantt) and the actual dates, side by side |
| [02_progress_tracking.md](02_progress_tracking.md) | Week-by-week progress log compared with the plan |
| [03_analysis_and_decisions.md](03_analysis_and_decisions.md) | Project analysis and the technical decisions we made, with reasons |
| [04_risk_analysis.md](04_risk_analysis.md) | Risks, their likelihood and impact, and how we mitigated them |
| [05_team_organization.md](05_team_organization.md) | Who did what, how decisions were made, how issues were handled |
| [06_acceptance_test_plan.md](06_acceptance_test_plan.md) | Feature-by-feature acceptance tests, results, and bugs found/fixed |
| [07_blocking_points.md](07_blocking_points.md) | Blocking points and conflicts met during the project and how they were solved |
